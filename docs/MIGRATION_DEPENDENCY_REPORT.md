# اعتماد الترحيلات — Aether BI

الترتيب ملفًا ملفًا بلا فجوات. كل ملف يعتمد على ما قبله. لا ملفات تراجع. كل ملف يُطبَّق داخل معاملة واحدة؛ الفشل لا يُسجَّل.

| الملف | يعتمد على | أثر بيانات |
| --- | --- | --- |
| `0001` النواة | لا شيء | جداول وصلاحيات قراءة فقط للمتصفح |
| `0002` العملاء | `0001` | لا حذف |
| `0003` المخزون الأول | `0001` | ينشئ `stock_movements` |
| `0004` المالية | `0001` | لا حذف |
| `0005` تمهيد الشركة | `0001`–`0004` | دالة مسحوب تنفيذها من المتصفح |
| `0006` دفتر المخزون | `0003` و`0004` | يسقط `stock_movements` فقط إذا كان فارغًا، وإلا يلغي نفسه |
| `0007` عروض الأسعار | `0002` و`0004` | يسقط قيد الحالة القديم ويستبدله |
| `0008` الأتمتة | `0006` | لا حذف صفوف |
| `0009` المنتجات | `0001` | يسقط سياسات المنتجات المفتوحة إن وُجدت. القيد `NOT VALID` لا يمس الصفوف القديمة |
| `0010` الدعوات | `0001` | لا حذف |
| `0011` المنظمة | `0001` | يعيد تعريف التمهيد ويسحب تنفيذه |
| `0012` دفتر الأستاذ | `0001` | لا حذف |
| `0013` المشتريات | `0006` | لا حذف |
| `0014` الشراء حتى الدفع | `0012` و`0013` | لا حذف |
| `0015` الإكمال المالي | `0012` و`0014` | لا حذف. الافتراض المحاسبي يبقى `invoice_basis` |
| `0016` تجميد الملاحظات | `0004` | لا يغيّر صفوفًا |
| `0017` المتوسط المتحرك | `0012` و`0015` | الافتراض المخزّن `order_price`. تجريبي |

لا `DELETE FROM` ولا `TRUNCATE` ولا إيقاف RLS. `GRANT` للمتصفح هو `SELECT`، مع تنفيذ دالتي العضوية فقط. `FORCE ROW LEVEL SECURITY` غير مفعّل، فدور `postgres` يتجاوز RLS والخادم يفرض العزل في الكود.

التحقق المعزول الموجود: `node scripts/throwaway-cluster.mjs --throwaway-local` مع `THROWAWAY_PG_PACKAGE`. نجح في 2026-10-28: 17 ملفًا، عزل `21/21`، تراجع بلا أثر.
