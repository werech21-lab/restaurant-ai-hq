# العوائق المتبقية — Aether BI

1. **نشر الإنتاج.** `aetherbi.com` يبني `main`. مركز ERP موجود في فرع التطوير ومعاينة Vercel فقط. يحتاج موافقة لدمج `main` أو لتغيير فرع الإنتاج.
2. **قاعدة الإنتاج.** مشروع Vercel بلا متغيرات بيئة. لا يُربط الموقع بـ Staging.
3. **ترحيل Staging.** النسخة الفيزيائية لم تُستعد. لا موافقة على `0001`–`0017`.
4. **المتوسط المتحرك.** تجريبي، والافتراض المخزّن `order_price`.
5. **دور `postgres`.** يتجاوز RLS. العزل في الخادم.
6. **المفتاح السري القديم.** غير مدوّر، والتطبيق لا يقرأه.
