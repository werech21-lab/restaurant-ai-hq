# تدقيق أمان Staging — Aether BI

التاريخ: 2026-10-28. النطاق: الكود والاختبارات المحلية. لم يُفحص المشروع المستضاف مباشرة.

## ما لم يُفعل

- لم يُخزَّن المفتاح السري ولا المفتاح القابل للنشر.
- لم يُعطَّل RLS ولم تُمنح صلاحيات واسعة.
- لم يُضف مفتاح service-role. التطبيق لا يقرأه.
- المتصفح لا يرى إلا `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY`.
- فحص ثابت جديد يرفض ظهور مادة المفاتيح الملصوقة داخل `src` و`scripts` و`database` و`e2e`.

## ضوابط مثبتة محليًا

| الضابط | الدليل |
| --- | --- |
| كل مسار API يمر من فحص الأصل ثم المصادقة ثم الصلاحية ثم حد المعدل | `protectedRoute`. حد الكتابة 60 في الدقيقة وحد القراءة 240 |
| الطلب المغيّر من أصل آخر يُرفض | تحذيرات الاختبارات الناجحة: `origin_mismatch` و`cross_site_fetch` و`origin_unreadable` |
| عضو بلا الصلاحية يأخذ 403 | Playwright: المشاهد لا ينشئ حسابًا |
| شركة أخرى تأخذ 403 على الترويسة و404 على المستند | `no_tenant_access` وعزل الفاتورة |
| جلسة تالفة تُخرج إلى تسجيل الدخول وواجهة API تعيد 401 | Playwright |
| ملف التجربة المحلي ينتهي بعد ساعتين ولا يُقبل إلا على `127.0.0.1` وخارج الإنتاج | `e2e-session` |
| RLS على أدوار `anon` و`authenticated` | خادم Playwright لا يبدأ إذا فشل فحص العزل. اختبارات العزل داخل Vitest نجحت |
| تكرار المفتاح بجسم مختلف | 422 وصف واحد |
| قيد غير متوازن | يبقى مسودة ويرفض الترحيل |
| مخزون غير كافٍ | 409 والرصيد لا يصبح سالبًا |
| فشل الترحيل | تراجع ولا سجل في `schema_migrations` |
| ترحيل بعيد بلا مرجع معتمد | يُرفض قبل الاتصال. القائمة فارغة |

## فجوات لا يغلقها الاختبار المحلي

- خادم التطبيق يتصل بمالك الجداول فيتجاوز RLS. عزل ذلك المسار من `tenant_id` في الاستعلامات. RLS يحمي المتصفح. هذا لم يُثبت على `pikqnlzkoaxoxpahtzvc`.
- المفتاح السري الذي ظهر في المحادثة مكشوف. لا يُستخدم حتى يُستبدل، وهو ليس كلمة مرور PostgreSQL.
- لا نسخة احتياطية للمستضاف لأنه لم يُتصل به.
- تحذير `pg`: استدعاء استعلام بينما العميل ينفّذ استعلامًا آخر. ظهر أثناء اختبار ناجح. ليس عطلًا مثبتًا، ويبقى تحت المراقبة.

## الحكم

الأمان المحلي يكفي لتجربة على `127.0.0.1`. لا يكفي لإعلان أمان المشروع المستضاف ولا للإنتاج.
