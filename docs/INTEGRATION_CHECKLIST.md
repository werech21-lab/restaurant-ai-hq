# Integration Checklist

آخر تحديث: 2026-10-27. يُستخدم هذا المستند عند كل دمج، ولتتبّع طابور الملفات المشتركة وحجز أرقام migrations.

## 1. بوابة الدمج (كل فرع/مهمة)

لا يُدمج شيء قبل أن تمر كل البنود، ويُسجَّل الناتج الحقيقي (لا افتراضات):

- [ ] المهمة داخل ملفات مالكها في `AGENT_OWNERSHIP_MATRIX.md`؛ أي ملف مشترك مرَّ عبر الطابور (القسم 3).
- [ ] العقد (أنواع، Zod، صلاحيات، أحداث) اعتُمد قبل بدء المستهلك.
- [ ] `npm run typecheck` ينجح.
- [ ] `npm run lint` ينجح.
- [ ] `npx vitest run --maxWorkers=2` ينجح؛ يُسجَّل عدد الملفات والاختبارات.
- [ ] كل منطق مالي أو مخزني جديد له اختبار: تقريب، صفر، سالب، عدم تطابق العملة.
- [ ] كل endpoint جديد: مصادقة + صلاحية RBAC + نطاق tenant + Zod + `api-access-matrix.test.ts`.
- [ ] كل جدول جديد: `tenant_id`, `created_at`, `updated_at`, `created_by`, RLS، وحالة في `architecture.test.ts` (`ownedTables`).
- [ ] كل create/update/delete للأعمال يكتب audit row؛ المالية والمخزون: `Idempotency-Key` و`version`.
- [ ] الأحداث تُنشر بعد commit فقط؛ المعالجات idempotent.
- [ ] لا `console.log`، لا `any`، لا `// TODO`، لا بيانات شكلية.
- [ ] لا سر في الملفات؛ لا `service_role` في مسارات العميل.
- [ ] واجهة جديدة: حالات التحميل والفراغ والخطأ، ar/en، RTL/LTR، KWD بثلاث خانات.
- [ ] لم تُشغَّل أي migration على قاعدة حية؛ لم يُعدَّل migration مدموج.
- [ ] الدمج إلى `main`: **موافقة المالك فقط**.

## 6. أوامر آمنة وغير آمنة للوكلاء

| آمن | ممنوع |
| --- | --- |
| `npm run typecheck`, `npm run lint` | `npm run db:migrate`, `npm run db:status:staging` |
| `npx vitest run <ملف> --maxWorkers=1` | `node scripts/migrate.mjs`, `staging-validate.mjs`, `products-report.mjs` مع أي ملف env |
| `npx vitest run --maxWorkers=2` (المنسّق فقط، واحد في كل مرة) | `git reset`, `git push --force`, `git clean`, حذف الأعمال غير الملتزم بها |
| قراءة الملفات | فتح `.env*` وطباعة أي قيمة سرية |
| `next build` (المنسّق فقط، واحد في كل مرة، بدون env حقيقي) | `next dev`/`start` مع env يشير لقاعدة حقيقية، أي نشر |
